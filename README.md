# 냉털 식단 🧊🍴

냉장고 속 재료만 적으면, 유통기한 급한 재료부터 챙기는 식단표와 집밥 레시피를 짜 주는 웹사이트예요.

👉 https://fridge-diet.vercel.app

## 만들게 된 이유

냉장고에 뭐가 있는지는 알아도 "그래서 오늘 뭐 해 먹지?"를 정하기가 늘 어려웠어요. 그러다 보면 두부나 요거트, 채소처럼 빨리 상하는 재료를 결국 버리게 되더라고요.

다이어트 식단을 찾아봐도 새 재료를 잔뜩 사야 하거나, 칼로리 숫자만 잔뜩 나와서 부담스러웠어요.

그래서 **이미 있는 재료로, 급한 것부터, 굶지 않고 든든하게** 먹는 식단을 알아서 짜 주는 도구를 만들었어요. 냉장고 털이(냉털)를 하면서 군것질은 조금씩 줄여 가는 게 목표예요.

## 사용법

1. **재료 적기**: 메모 앱에 적어 둔 냉장고 목록을 통째로 붙여넣고 **알아서 정리하기**를 눌러요.
   - "냉장고 / 냉동고 / 실온" 제목으로 나눠 적었다면 바로 칸별로 정리돼요.
   - 제목 없이 적은 재료는 AI가 자리를 찾아줘요.
   - 칸에 직접 적어도 돼요.
2. **조건 고르기**: 먹을 끼니(아침·점심·저녁)와 기간(1일~2주), 못 먹는 음식을 정해요. 성별·키·체중은 적고 싶을 때만 적어요.
3. **식단 짜기**를 누르면 10~30초 안에 식단이 나와요.
   - **먼저 쓸 재료**: 냉장(주황)·냉동(파랑)·실온(노랑) 색으로 표시돼요.
   - **날짜별 식단**: 먹은 끼니를 체크할 수 있어요.
   - **레시피**: 집에서 쓰는 계량(큰술·컵)으로 적혀 있어요.
4. **다시 짜기**: 재료가 바뀌면 **이 재료 고쳐서 다시 짜기**를 눌러요. 지금 식단은 **지난 식단**에 남아요.
5. **아이폰에서 앱처럼 쓰기**: 사파리에서 공유 → **홈 화면에 추가**를 눌러요.

### 알아두면 좋은 점

- 식단 짜기와 AI 재료 정리는 합쳐서 **하루 100회**까지 쓸 수 있어요(자정에 다시 채워져요).
- 지난 식단과 입력값은 **이 기기 브라우저에만** 저장돼요. 맨 아래 **이 기기 기록 모두 지우기**로 언제든 지울 수 있어요.
- 목표 체중이 저체중 범위(BMI 18.5 미만)면 한 번 확인한 뒤, 감량이 아니라 골고루 챙겨 먹는 식단으로 짜고 주의 표시를 붙여요.
- 칼로리 숫자나 극단적인 제한은 나오지 않아요. 일반적인 식생활 참고용이니, 건강 문제가 있다면 의사·영양사와 상담해 주세요.
